# IPTV M Pro for Windows

Download the installer from the [latest release](../../releases/latest): `IPTV-M-Pro-Setup-1.0.5.exe`.

1. Run the installer. Windows may show "Windows protected your PC" because the installer is not code-signed yet: choose **More info**, then **Run anyway**.
2. Open **IPTV M Pro** from the Start menu or the desktop.
3. Add your own M3U or Xtream Codes playlist in Settings → Playlists.

IPTV M Pro is a player only. It does not provide any channels, playlists or content.

Requirements: Windows 10 or 11, 64-bit.
