# IPTV M Pro — downloads

**Download page with install steps and help: https://iptv-m-pro-site.vercel.app**

IPTV M Pro is a player only. It does not provide any channels, playlists or content: add your own M3U or Xtream Codes playlist in Settings.

## Mac

**[Download IPTV-M-Pro-1.0.4.dmg](https://github.com/mahmoudstate/iptv-m-pro-releases/releases/download/mac-v1.0.4/IPTV-M-Pro-1.0.4.dmg)**

1. Open the DMG and drag **IPTV M Pro** to **Applications**.
2. Open it from Launchpad or Applications.

Signed and notarized by Apple. macOS 13 Ventura or later, Apple silicon and Intel.

## Windows

**[Download IPTV-M-Pro-Setup-1.0.8.exe](https://github.com/mahmoudstate/iptv-m-pro-releases/releases/download/windows-v1.0.8/IPTV-M-Pro-Setup-1.0.8.exe)**

1. Run the installer. Windows may show "Windows protected your PC" because the installer is not code-signed yet: choose **More info**, then **Run anyway**.
2. Open **IPTV M Pro** from the Start menu or the desktop.

Windows 10 or 11, 64-bit.
